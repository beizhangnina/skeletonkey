Tendata

No public API Checked 2026-10-25

Global trade-intelligence platform selling customs import/export records, buyer and supplier discovery and decision-maker contacts across 228+ countries, with an enterprise API delivered as part of a sales-negotiated contract.

No public API

We found no self-serve developer API from this vendor. Programmatic access is offered through Glasser and Monid, which collects the data for you.

When to pick which

  • No self-serve direct route (sales only); the Glasser and Monid routes are self-serve.

  • The Monid route is listed unverified: no price was readable there on 2026-10-25.
  • The Monid route can be paid per call in USDC over x402.

Route notes

Direct
No public self-serve API on the vendor's own pages.
Glasser
Glasser showed 16 Tendata endpoints, with three count/search calls at the cheapest rate of $0.0005 per call and the record-level ones priced per result. Free credit or trial: Every new workspace starts with a signup Grant of free balance.
Monid
Monid's Tendata page loads but its endpoint panel says 'No endpoints here yet' and no Tendata price is shown anywhere on it. Free credit or trial: New accounts start with $1 in free credit.
