RapidAPI (Nokia API Hub)

Verified Checked 2026-10-25

A long-running public API marketplace, now branded Nokia API Hub, where one account key proxies requests to thousands of third-party APIs listed by their publishers. Each API is subscribed to separately on a monthly plan, so the single key unifies auth and billing but not entitlement.

How it bills
Per-API recurring monthly subscription plans (many with a free BASIC tier) plus overage fees per call above a plan's quota; invoices under 50 US cents roll into an account balance until the threshold is passed. Free APIs need no card, pay-per-use and freemium APIs do.

Fees stated
New: Starting December 2025, each subscription will include 10 GB of bandwidth per billing cycle at no cost. After that limit, a fee of $1 per additional 1 GB of traffic will apply, calculated proportionally based on total usage. This fee will be charged to the consumer and helps cover infrastructure costs, keeping the platform reliable and scalable for everyone.
