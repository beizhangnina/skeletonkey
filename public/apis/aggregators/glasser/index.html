Glasser

Verified Checked 2026-10-25

A single-account gateway that resells paid data endpoints from specialist providers (SEO, people/company, web, places, market data) to AI agents. The agent searches a catalog, inspects an endpoint's schema and price, then executes it as a billed Run against one workspace balance.

How it bills
Pay-per-call from a prepaid workspace balance; no per-provider subscriptions. Search and Inspect are free; each Run is charged (flat, per-result with cap, per-token with cap, or base+per-result), with separate charge rules for NO_RESULT, PROVIDER_ERROR, TIMED_OUT and INTERNAL outcomes. Every new workspace starts with a signup Grant of free balance.
