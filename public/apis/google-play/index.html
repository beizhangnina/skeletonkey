Google Play

No public API Checked 2026-10-26

Google Play is Google's Android app, game and digital content store. The only APIs Google publishes for it are publisher-scoped: the Google Play Developer API (androidpublisher v3) for managing your own app's releases, listings, purchases and review replies, plus the Play Developer Reporting API.

No public API

We found no self-serve developer API from this vendor. Programmatic access is offered through Glasser, which collects the data for you.

Ways to reach this data: direct from the vendor, or through an aggregator gateway that already holds the key. Every figure here is ours, read on the checked date; unverified routes carry no confirmed price.

When to pick which

  • No self-serve direct route (no public API on the vendor pages); the Glasser and Apify Store routes are self-serve.
  • Glasser exposes 2 endpoints; the vendor publishes no self-serve API we could verify.
  • Listed prices: direct $0 per call; Glasser $0.0005 per call; Apify Store from $0.10 / 1,000 reviews.
  • The Apify Store route can be paid per call in USDC over x402.

Route notes

Direct
No public self-serve API on the vendor's own pages.
Glasser
Glasser's Google Play page has two endpoints, books search and movies search, both $0.0005 per call. Free credit or trial: Every new workspace starts with a signup Grant of free balance.
Apify Store
This Google Play reviews Actor (3,218 users, 5.0 rating) shows 'from $0.10 / 1,000 reviews' on its Apify pricing tab. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.
