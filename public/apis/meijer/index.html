Meijer

No public API Checked 2026-10-25

Midwestern US supercenter chain selling groceries, pharmacy, electronics and home goods through its stores and consumer e-commerce site; its Azure API Management portals are internal and are not open to outside developers.

No public API

We found no self-serve developer API from this vendor. Programmatic access is offered through Glasser, which collects the data for you.

When to pick which

  • No self-serve direct route (no public API on the vendor pages); the Glasser and Apify Store routes are self-serve.
  • Glasser exposes 1 endpoint; the vendor publishes no self-serve API we could verify.
  • Listed prices: Glasser $0.011 per call; Apify Store from $0.01 / result.
  • The Apify Store route can be paid per call in USDC over x402.

Route notes

Direct
No public self-serve API on the vendor's own pages.
Glasser
Provider page listed 1 published endpoint, Meijer Product Details (/product), at $0.011 per call. Free credit or trial: Every new workspace starts with a signup Grant of free balance.
Apify Store
Apify Actor page for the Meijer Scraper showed a pricing badge of from $0.01 / result. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.
