Homes.com

No public API Checked 2026-10-25

Consumer real-estate marketplace (owned by CoStar) for buying, selling and renting homes, with agent directories and listing marketing products for agents and brokerages.

No public API

We found no self-serve developer API from this vendor. Programmatic access is offered through Monid, which collects the data for you.

When to pick which

  • No self-serve direct route (no public API on the vendor pages); the Monid and Apify Store routes are self-serve.
  • Listed prices: Monid $0.01; Apify Store from $1.00 / 1,000 extracted properties.
  • The Monid and Apify Store routes can be paid per call in USDC over x402.
  • The Monid and Apify Store routes start new accounts with free credit.

Route notes

Direct
No public self-serve API on the vendor's own pages.
Monid
Monid's Homes.com page listed no endpoints yet, but its property walkthroughs priced homes.com /search_properties_for_sale at $0.01, rent search at $0.02 and property details at $0.03. Free credit or trial: New accounts start with $1 in free credit.
Apify Store
The most-used Homes.com Actor (about 16k runs) shows pay-per-result pricing from $1.00 per thousand extracted properties. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.

Listed in: Monid.
