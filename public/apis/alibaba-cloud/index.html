Alibaba Cloud (Model Studio)

Verified Checked 2026-10-25

Alibaba Cloud Model Studio serves the Qwen and Wan model families over OpenAI-compatible and Anthropic-compatible REST endpoints: text generation, vision and omni-modal understanding, image/video/3D generation, speech and music, embeddings and rerank, plus batch inference, fine-tuning and dedicated deployment.
