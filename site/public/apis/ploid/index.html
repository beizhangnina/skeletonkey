Ploid

Verified Checked 2026-10-25

People-search and identity-research API over a large index of individuals: query for people in natural language, pull full public profiles, build curated lists, find work/personal emails and phones, and get evidence-backed person reports with field-level provenance. Available as REST, MCP and CLI.
