Y Combinator

No public API Updated 2026-10-26

Startup accelerator: four times a year it invests $500k in a batch of startups and runs them through a three-month programme, and it publishes a public startup and founder directory. It is not an API vendor.

What differs between them

  • No self-serve direct route (no public API on the vendor pages); the Glasser, Monid, Apify Store and RapidAPI (Nokia API Hub) routes are self-serve.
  • Glasser exposes 6 endpoints; the vendor publishes no self-serve API we could confirm.
  • Listed prices: Glasser $0.011 per call; Monid $0.01; Apify Store from $10.00 / 1,000 results; RapidAPI (Nokia API Hub) Basic $0.00 /mo (24 requests per day).
  • The Monid and Apify Store routes can be paid per call in USDC over x402.

Route notes

Direct
No public self-serve API on the vendor's own pages.
Glasser
Glasser's Y Combinator page listed all six endpoints, including Company Profile and Partners, at a flat $0.011 per call. Free credit or trial: Every new workspace starts with a signup Grant of free balance.
Monid
Monid's endpoint catalog section for this provider reads 'No endpoints here yet', but its how-to guide on the same page lists three ycombinator endpoints (/get_company, /search_companies, /search_jobs) at $0.01 per call; /get_partners was not shown. Free credit or trial: New accounts start with $1 in free credit.
Apify Store
The most-used Y Combinator scraper on Apify Store (1,649 users) showed $10.00 per 1,000 results. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.
RapidAPI (Nokia API Hub)
The Free Y Combinator Jobs API pricing tab on RapidAPI showed only a Basic plan at $0.00/mo capped at 24 requests a day. Free credit or trial: Per-API recurring monthly subscription plans (many with a free BASIC tier) plus overage fees per call above a plan's quota
