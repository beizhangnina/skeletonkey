API index / real-estate

RentCast API

Verified Checked 2026-10-25

US real estate data API: property records and owner details, AVM value and rent estimates, for-sale and rental listings, and local market statistics.

API surface

Official docs
https://developers.rentcast.io/reference/introduction
EndpointDoesReturnsDocs
GET /propertiesSearch property records by address, city, state, zip code, or a circular lat/long radius, with filters like property type, beds, baths, size and sale date; paginated.List of property records with structural attributes, features, tax assessments, sale history and owner details.Docs
GET /properties/randomReturns a random sample of property records, up to a specified limit, useful for testing or sampling.List of randomly selected property records including attributes, tax assessments, sale history and owner details.Docs
GET /avm/rent/long-termReturns a long-term rent estimate for a property by address or latitude/longitude, with tunable comp settings such as maxRadius, daysOld and compCount.Rent estimate, subject property attributes, and comparable rental listings sorted by correlation.Docs
GET /marketsReturns aggregate sale and/or rental market statistics and historical trends for a single US zip code, with dataType and historyRange options.Aggregate market data in saleData and rentalData fields, plus historical record entries.Docs
GET /listings/rental/long-term/{id}Returns a single long-term rental listing matching an internal property/listing id obtained from /properties, /avm or /listings endpoints.Listing record with listed rent, listing date, status, listing contacts and property attributes.Docs
