TinyFish

Checked 2026-10-25

FREE

Web-access infrastructure for AI agents, all behind one API key: structured web search, URL-to-clean-content fetch, multi-step browser automation agents, cloud browser sessions, scheduled page/topic monitoring, and Mako, their web-native model. LLM inference, residential proxies, anti-bot handling and run storage are bundled into each run.
