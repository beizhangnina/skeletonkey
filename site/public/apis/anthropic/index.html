Route notes

Apify Store
Bring-your-own-key proxy that calls the Claude API from Apify; this Apify fee sits on top of what Anthropic bills directly. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.
