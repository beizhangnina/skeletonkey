Arena (formerly LMArena)

No public API Checked 2026-10-25

Cost not verified

Runs anonymous side-by-side model battles across text, image, video, code, search and agents, and turns the public's votes into Bradley-Terry leaderboards. It is a consumer web app plus paid evaluation work for model labs, not a developer API.

What differs between them

  • No self-serve direct route (no public API on the vendor pages); the Glasser, Monid and Apify Store routes are self-serve.
  • Glasser exposes 11 endpoints; the vendor publishes no self-serve API we could verify.
  • Listed prices: Glasser $0.011 per call; Monid $0.01; Apify Store from $0.50 / 1,000 record scrapeds.
  • The Monid and Apify Store routes can be paid per call in USDC over x402.
