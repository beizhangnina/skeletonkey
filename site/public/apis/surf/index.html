Surfapi

Checked 2026-10-25

FREE

Search-results API: one GET to /search.json returns JSON for Google web, images, news, shopping, hotels, hotels-autocomplete and flights, plus Hotelbeds hotels. Request params and response shapes mirror the common hosted SERP APIs, so clients migrate by swapping host and key.
