Product Hunt

Checked 2026-10-26

GraphQL API over Product Hunt's launch data - posts, products, topics, collections, comments and users - plus user-scoped actions for apps authorised by a Product Hunt user.

API surface

Official docs
https://api.producthunt.com/v2/docs

GET /v2/oauth/authorizeRedirect the user here to log in to Product Hunt and grant the app access; on approval the user is returned to redirect_uri with a code (access grant).An HTML authorization page after which the user is redirected back to redirect_uri with a code parameter and state.Docs
POST /v2/oauth/tokenExchange the access_grant code (authorization_code grant) together with client_id, client_secret and redirect_uri for an access token.JSON body containing access_token and token_type (bearer).Docs
GET /v2/api/graphqlGraphQL access using a client-level token for public fields; user-level fields such as isVoted return default values (false).JSON GraphQL response where user-scoped fields fall back to defaults and viewer is null.Docs

What differs between them

  • Neither the direct signup nor the Glasser and Apify Store routes ask for a card.
  • Only the direct route exposes all endpoints; Glasser exposes 1 endpoint.
  • Listed prices: Glasser $0.0005 per call; Apify Store from $1.80 / 1,000 products.
  • The Apify Store route can be paid per call in USDC over x402.

Route notes

Glasser
Glasser's Product Hunt page had one published endpoint, a product detail lookup at $0.0005 per call. Free credit or trial: Every new workspace starts with a signup Grant of free balance.
Apify Store
A widely used Apify Actor for Product Hunt launches quotes $1.80 per 1,000 products on its store page, with optional email enrichment billed separately. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.
