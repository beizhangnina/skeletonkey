API index / web-search

Octen

Verified Checked 2026-10-25

Real-time search and retrieval APIs for LLMs and agents: web, broad (query-decomposed), news, business, image and video search, URL extraction to Markdown, text/multimodal embeddings, plus deep research, grounded answers and grounded image/video generation.

API surface

Official docs
https://docs.octen.ai/
EndpointDoesReturnsDocs
POST /pulse-searchGenerates the most likely URLs for a query quickly and returns them in ranked order; lite mode gives URL and title, standard adds highlights, content, images.Ranked results with title and URL (lite), plus highlights, full content, and images in standard mode.Docs
POST /broad-searchSplits a query into several related sub-queries, searches them concurrently, and groups the results under each sub-query.The generated sub-queries plus per-sub-query result lists (title, url, highlight, full content, authors, timestamps).Docs
POST /searchWeb Search: searches the live web for ranked results with optional filters, highlights, and full page content.Ranked web results with highlights and full content.Docs
POST /extractTurns URLs into clean markdown content, with optional query-focused highlights, page classification, and multimedia resources.Clean markdown content extracted from the supplied URLs.Docs
POST /place-searchSearches for places matching a query and returns each as a place card with address, coordinates, contact details, opening status, rating.Place cards plus optional web results and query/location metadata.Docs
