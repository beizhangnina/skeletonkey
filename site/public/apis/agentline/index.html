API index / communications

AgentLine

Verified Checked 2026-10-25

Supplies US and Canadian phone numbers for AI agents to make and receive calls and exchange SMS through an API.

API surface

Official docs
https://docs.agentline.cloud
EndpointDoesReturnsDocs
POST /v1/agentsCreate a new AI voice agent with a system prompt, greeting, voice, and voicemail settings; then attach a phone number to it.The created agent object, including id, account_id, name, voice settings, and created_at.Docs
GET /v1/eventsPoll the event mailbox for call completions, transcripts, and failures; events are deleted once consumed.Pending telephony events, filterable by agent_id and event_type, with a limit of 1-200.Docs
PATCH /v1/numbers/{number_id}/reassignMove an existing phone number from one AI agent to another; the target agent must not already have an active number.Successful response (200); the number stays active, only agent ownership changes.Docs
POST /v1/callsPlace an outbound call from the agent's number; the agent handles the conversation using its prompt, voice, and greeting.Right after dialing: call id, agent_id, from_number, to_number, direction, status, started_at.Docs
GET /v1/billing/expenditure/numbersList phone number provisioning charges, paginated by limit and offset.Cost of each phone number bought, including the number, country, and current status.Docs

What differs between them

Route notes
