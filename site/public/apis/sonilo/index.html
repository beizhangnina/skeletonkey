API index / generative-media

Sonilo API

Updated 2026-10-25

FREE

Generates licensed music, sound effects, combined soundtracks, dubbing and subtitle translation from a video, text prompt or audio file, plus audio ducking and video-to-brief analysis, as async REST jobs.

API surface

Official docs
https://platform.sonilo.com/docs
EndpointDoesReturnsDocs
POST /v1/text-to-musicGenerate music from a text prompt and a duration; streaming or async modes.application/x-ndjson stream of title, audio_chunk, complete, error events (default), or 202 JSON with task_id in async mode.Docs
POST /v1/video-to-musicGenerate music scored to a video file or URL, with optional prompt, segments, and output format.NDJSON stream of audio events in stream mode, or 202 JSON with task_id to poll in async mode.Docs
POST /v1/video-to-sfxGenerate sound effects synchronized to a video, accepting a video file or video_url with optional prompt or segments.202 Accepted JSON with task_id and status processing; poll GET /v1/tasks/:task_id for the audio result.Docs
GET /v1/tasks/{task_id}Retrieve the status and results of an async generation task such as SFX, combined sound, or audio ducking.Task status and result URLs, including audio.url, content_type and file_size on success.Docs
GET /v1/account/usageRetrieve credit usage for the account, with a summary plus daily breakdown over a lookback window.JSON with summary totals (requests, duration, cost, period) and a per-day daily breakdown.Docs
