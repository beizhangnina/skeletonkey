SerpApi

Verified Checked 2026-10-25

Cost not verified

Scrapes and parses search engine results pages (Google, Bing, Baidu, Yandex, maps, shopping and more) and returns them as structured JSON. Monthly subscription plans metered in successful searches.

GET /searchMain search endpoint; scrapes Google search results when called with engine=google plus query parameters such as q and location.Google search page results as structured data (JSON by default; Markdown if requested via output=md).Docs
