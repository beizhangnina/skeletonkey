Shelved

SkeletonKey currently sets LLM-model APIs aside from its default catalog while it focuses on tool and data APIs for agents. The page stays up and the data is kept here -- it is just left out of the API index, search, llms.txt and sitemap by default.

Serves Jev, a 'System One' model that takes a block of state plus a set of typed questions and returns each answer as a structured decision - boolean/noul, choice or score - with a calibrated probability, through a single POST /v1/systemone endpoint.
