API index / web-search

Keenable

Verified Checked 2026-10-25

Independent web search and page-fetch API built for AI agents and labs: POST /v1/search over its own 100B+ document index, GET /v1/fetch for the indexed or live copy of a page, with MCP server and CLI front ends.

EndpointDoesReturnsDocs
POST /v1/searchSearch Keenable's web index and return ranked pages with URLs, titles, and snippets.Ranked search results with URLs, titles, and snippets.Docs

POST /v1/monitorsCreate a monitor that watches a topic for new pages or watches one page for changes.The created monitor; on creation, the response includes the webhook signing secret.Docs
