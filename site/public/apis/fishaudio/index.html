Fish Audio

Verified Checked 2026-10-25

Free / pay as you go

Text-to-speech, voice cloning/design and speech recognition models, offered through a REST/WebSocket API and a web app.

API surface

Official docs
https://docs.fish.audio
EndpointDoesReturnsDocs
POST /v1/ttsGenerate speech audio from text, choosing a voice via reference_id, output format, and the model header.Streamed audio file in the requested format (e.g., mp3).Docs
POST /v1/asrTranscribe audio to text, with the transcription model selected by the model header.Transcript, optionally with speaker markers, emotion cues, and timestamps.Docs
POST /v1/audio/infillRegenerate a span of an existing recording with a revised transcript, keeping the rest of the take.The whole take back with only the specified span regenerated.Docs
POST /v1/voice-designGenerate candidate voices from a natural-language description prompt.Candidate voices generated from the prompt.Docs
POST /v1/agent/background-soundsUpload a custom background-sound audio clip for a voice agent, sent as multipart/form-data.Clip object with _id, name, duration_seconds, size_bytes, created_at.Docs
