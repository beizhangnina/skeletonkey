Yahoo Finance

No public API Checked 2026-10-25

Consumer finance site: stock, ETF and crypto quotes, charts, company news, portfolio and watchlist tracking, screeners, and a paid premium research tier. Yahoo publishes no developer API for this data.

What differs between them

  • No self-serve direct route (no public API on the vendor pages); the Monid, Apify Store and RapidAPI (Nokia API Hub) routes are self-serve.
  • Listed prices: Monid $0.05; Apify Store from $0.90 / 1,000 results; RapidAPI (Nokia API Hub) Basic $0.00 /mo — Requests 500 / Month.
  • The Monid and Apify Store routes can be paid per call in USDC over x402.
  • The Monid, Apify Store and RapidAPI (Nokia API Hub) routes start new accounts with free credit.

Route notes

Direct
No public self-serve API on the vendor's own pages.
Monid
Monid's Yahoo Finance page said no endpoints are published yet, but its stock-quote walkthrough priced yahoo-finance /get_quote at $0.05. Free credit or trial: New accounts start with $1 in free credit.
Apify Store
The most-used Yahoo Finance Actor (over 700k runs) shows a headline price of $0.90 per thousand results. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.
RapidAPI (Nokia API Hub)
The YH Finance listing's pricing tab shows a free Basic tier of 500 requests a month, then Pro at $10.00/mo. Free credit or trial: Per-API recurring monthly subscription plans (many with a free BASIC tier) plus overage fees per call above a plan's quota
