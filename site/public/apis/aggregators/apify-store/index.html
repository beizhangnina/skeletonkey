Apify Store

Verified Checked 2026-10-25

A marketplace of hosted scrapers and automation programs called Actors, each callable as a REST job that returns structured data. One Apify account and token reaches every Actor, and agents can also connect over a remote MCP server or pay per run without an account using x402 or Skyfire.

Before you route through this

SkeletonKey lists aggregator gateways as directory entries, not as a recommended access layer. A gateway holds one key that stands in for many vendors; keeping your own account and key with each vendor keeps you in control of your own data, limits and billing. Register locally with SkeletonKey instead where you can — the details below are what we read on this gateway's own pages, for reference.

How it bills
Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage. Each Store Actor is priced by its developer as pay per event, pay per usage (compute units), or both. Free-plan access pauses when the monthly credit runs out instead of billing.
