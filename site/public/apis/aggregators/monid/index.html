Monid

Verified Checked 2026-10-25

An aggregation gateway where an agent discovers, inspects and runs third-party data endpoints at runtime through one key and one wallet, instead of signing up with each provider. Exposed as an HTTP API, MCP server, CLI and agent Skill, with an optional x402 crypto payment path.

Before you route through this

SkeletonKey lists aggregator gateways as directory entries, not as a recommended access layer. A gateway holds one key that stands in for many vendors; keeping your own account and key with each vendor keeps you in control of your own data, limits and billing. Register locally with SkeletonKey instead where you can — the details below are what we read on this gateway's own pages, for reference.

How it bills
Pay-as-you-go from a prepaid wallet, no subscriptions or contracts: per-call flat fee or per-result fee with an optional base fee. Discover and inspect are free; runs are billed. New accounts start with $1 in free credit. Alternatively, runs can be paid per-call on-chain in USDC via x402 with no workspace balance at all.
Payment methods
card, credits (prepaid wallet), crypto/x402 (USDC on Base mainnet or Monad mainnet)
Fees stated
Minimum price: $0.01. Monid raises the advertised price to this floor if the run's quote is lower.
