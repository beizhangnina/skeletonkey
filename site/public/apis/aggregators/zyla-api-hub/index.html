Zyla API Hub

Verified Checked 2026-10-25

An API marketplace that proxies a large catalog of data, finance, weather, validation and AI APIs through one gateway and one key. Agents can reach the whole catalog over Zyla's MCP server and be billed per successful call, while developers subscribe per API from their own code.

Before you route through this

SkeletonKey lists aggregator gateways as directory entries, not as a recommended access layer. A gateway holds one key that stands in for many vendors; keeping your own account and key with each vendor keeps you in control of your own data, limits and billing. Register locally with SkeletonKey instead where you can — the details below are what we read on this gateway's own pages, for reference.

How it bills
Two paths from one account: pay-per-call through the Zyla MCP server (no subscription, no minimum, charged only on successful calls, requires a credit card on file or the agent receives a 402 payment link), or per-API monthly subscription plans with a fixed call quota and a 60/120/240 requests-per-minute cap.
