Idealist

No public API Checked 2026-10-26

Cost not verified

Idealist is a nonprofit jobs, internship and volunteering marketplace. It exposes a Job Posting API that lets approved US-based organizations publish listings programmatically by spending prepaid job credits, plus partner-only Listings and Apply APIs for syndicating its volunteer/job database.

Endpoints: A Job Posting API exists but is gated to approved US organizations with purchased job credits; production keys are issued only on request.

What differs between them

  • No self-serve direct route (sales only); the Monid and Apify Store routes are self-serve.
  • Listed prices: direct $145 per call; Monid $0.01; Apify Store from $3.00 / 1,000 job results.
  • The Monid and Apify Store routes can be paid per call in USDC over x402.
  • The Monid and Apify Store routes start new accounts with free credit.

Route notes

Direct
No public self-serve API on the vendor's own pages.
Monid
Monid's endpoint catalog section for this provider reads 'No endpoints here yet', but its how-to guide on the same page lists one Idealist endpoint, /search_jobs, at $0.01 per call. Free credit or trial: New accounts start with $1 in free credit.
Apify Store
An Idealist.org nonprofit-jobs actor on Apify Store (35 users) showed $3.00 per 1,000 job results. Free credit or trial: Free plan renewing $5/month of prepaid usage credit, plus paid monthly plans ($19 Starter / $199 Scale / $999 Business) that add pay-as-you-go usage.
