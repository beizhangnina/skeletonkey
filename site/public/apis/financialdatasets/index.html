Financial Datasets

Updated 2026-10-25

PAYG · $20 minimum top-up

US stock-market data API for agents: standardized and as-reported financial statements, SEC filings, earnings, operating KPIs, guidance, insider and institutional ownership, prices and news, each value cited back to its source document.

API surface

Official docs
https://docs.financialdatasets.ai/
EndpointDoesReturnsDocs
GET /activist-ownershipReturns activist investor stakes in US public companies from SEC Schedule 13D filings; filter by ticker or filer_cik, optionally with full amendment history.JSON with an activist_owners array (ticker, filer_cik, percent_of_class, voting/dispositive power, filing_date, is_latest, etc.) and next_page_url.Docs
GET /insider-trades/sale-noticesReturns SEC Form 144 notices of proposed insider stock sales, updated within minutes of each filing.JSON with a sale_notices array (ticker, issuer, name, securities, acquisitions, sales_past_3_months, filing_url) and next_page_url.Docs
GET /iposReturns SEC IPO registration filings (S-1, S-1/A, F-1, F-1/A, 424B4, 424B1) minutes after SEC acceptance.JSON with an ipos array (company_name, form_type, ticker, exchange, expected_offering_price, price range, status, financials) and next_page_url.Docs
GET /activist-ownership/tickers/Lists the companies that have activist stakes recorded on the activist ownership endpoint.A list of companies with activist stakes.Docs
GET /activist-ownership/filers/Looks up activist filers and their CIKs by owner name (prefix, case-insensitive), paged with limit.Matches for the name prefix plus a total count of all matches alongside the returned page.Docs
