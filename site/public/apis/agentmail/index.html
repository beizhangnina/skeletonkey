AgentMail

Updated 2026-10-25

FREE

Email infrastructure built for AI agents: programmatically create inboxes and send, receive and search mail over a REST API with webhooks.

API surface

Official docs
https://docs.agentmail.to
EndpointDoesReturnsDocs
POST /v0/agent/sign-upCreates a new agent organization with an inbox and an API key, sending a 6-digit OTP to the human's email for verification.Signup response (agent_AgentSignupResponse); errors return 400 validation errors.Docs
POST /v0/agent/verifyVerifies an agent organization with the 6-digit OTP emailed to the human, upgrading it to agent_verified and applying Free plan entitlements.Verification response (agent_AgentVerifyResponse).Docs
POST /v0/agent/humanAttaches a human to an unverified agent organization by emailing them a 6-digit OTP to submit to the verify endpoint.Attach-human response (agent_AgentAttachHumanResponse); 400 validation errors, 409 conflicts.Docs
POST /v0/inboxes/{inbox_id}/filesStarts a file upload for an inbox: creates a pending file at a path and returns an upload target to PUT bytes to.Create-file response with a pending file and upload target; 400/403/404/409 errors possible.Docs
GET /v0/pods/{pod_id}/forwardingRetrieves the forwarding destinations configured at the pod level, which its inboxes inherit when they set none.200 with destinations (nullable string list) and unverified addresses; 403/404 errors.Docs
